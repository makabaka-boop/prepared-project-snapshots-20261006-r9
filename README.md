# DXF 块实例圆弧验图页面

浏览器内运行的**单页验图工具**：导入平面 ASCII DXF，展开 BLOCK / INSERT 层级，
精确量测每个**真实插入实例**上的 LINE 与 LWPOLYLINE bulge 圆弧（含非均匀缩放、镜像、
旋转后的参数曲线），审图结果可指回具体插入实例。

## 要解决的问题

同一个 CAD 块经**镜像**或**不同横纵比例**插入后，块定义里的 bulge 圆弧在该实例上
已不是原半径的圆（变为镜像/椭圆弧）。直接看块定义会对错位置、错半径、错方向。
本工具对每个实例独立展开并量测：

- 图纸坐标端点、弧中点、弧内 X/Y 极值点；
- 局部与图纸两个层面的扫掠方向（CCW/CW，镜像会反转）；
- **包含弧内极值**的精确包围盒（解析求解，不是连接端点的直线段，也不靠采样碰运气）；
- 每个实例保留从图纸根到叶子的**完整插入路径**与稳定标识。

## 接收 / 拒绝范围（硬限制）

| 类别 | 规则 |
|---|---|
| 实体 | 仅 `LINE`、`LWPOLYLINE`、`BLOCK`、`INSERT`；遇到 ARC/CIRCLE/TEXT/MINSERT/TRACE/XREF 等直接拒绝并指明原因 |
| 平面 | Z 必须为 0（端点/标高/插入点），挤出方向必须是默认 `(0,0,1)` |
| 嵌套 | 块嵌套最多 **4 层**，展开实体最多 **60 个**（只数 LINE/LWPOLYLINE，不计 INSERT） |
| 拒绝 | 循环块引用、引用未知块、零缩放（任一轴）、阵列（70/71≠1）、外部参照块、非零厚度/宽度 |
| 变换 | 自行组合块基点平移、插入缩放、旋转与全部父变换；不做阵列、XREF、文字、宽线 |

## bulge 与变换约定

- `bulge k = tan(θ/4)`，θ 为有向圆心角；`k>0` 为局部 CCW，`k<0` 为 CW。
- 闭合多段线**最后一个顶点**的 bulge 作用于“末点 → 首点”的闭合段；开放多段线末顶点 bulge 不产生段。
- 实例矩阵（块基点 `b`、插入参数 `x,y,sx,sy,r`）：

```
M_insert = T(x,y) · R(r) · S(sx,sy) · T(−b)
M_world  = M_parent · M_insert          （嵌套时逐层左乘）
```

- 非均匀缩放 / 镜像后圆弧成为椭圆弧：保留变换后的**参数曲线**，
  包围盒由 `X(t)=Kx+A·cos t+B·sin t`、`Y(t)=…` 的驻点 `t=atan2(±…)` 解析求出，
  再用角度区间包含判定过滤弧外候选；`det(M)<0` 时图纸方向相对局部反转。
- 显示用细分折线仅用于绘制与拾取；**量测值全部来自解析端点/驻点**。

## 隔离性

每次“重展开”都基于**不可变的原始解析文档**创建全新几何对象；修改某一实例的插入点/
比例/旋转只写进该实例 id 的覆盖表（`buildModel(doc, {id: {sx,…}})`），
不改动共享块定义与兄弟实例；视图缩放只改变显示矩阵，不改变任何量测值。

## 文件结构

```
index.html           验图页面
css/app.css
js/dxf-core.js       解析 / 校验 / 展开 / 仿射矩阵 / bulge 圆弧 / 解析包围盒（无依赖，Node 通用）
js/dxf-writer.js     DXF 写出辅助（仅示例与测试使用）

sample.dxf           示例 DXF（与“加载示例”一致）
compose.yaml         静态发布
Dockerfile           nginx 静态站点镜像
```

## 运行 / 测试

```bash
# 本地测试（无需浏览器）
node js/test.js

# 本地预览
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080

# 发布
docker compose up -d --build
```

页面操作：导入 DXF（按钮或拖入 `.dxf`）→ 左侧树或画布中点选实例 →
右侧查看段量测、可修改该实例插入参数 → “审图记录”页把问题挂到具体实例并导出 JSON。

## 测试覆盖要点

- 非零块基点平移、两层嵌套父变换组合（手工坐标核对）；
- 负比例单轴/双轴镜像后的方向反转与端点；
- bulge ±0.5 / 1 / 2 的圆心、半径、sweep、弧中点；
- 非均匀缩放与“非均匀+旋转”的包围盒对 20–50 万点采样（误差 1e-5）；
- 跨象限优弧与象限角点驻点（精确包含/排除）；
- 闭合段 bulge 归属；
- 循环/自引用、未知块、零缩放、5 层与 61 实体、非零 Z、非默认挤出、阵列、宽线、XREF、坏组码；
- 同块多实例与嵌套兄弟实例的修改隔离；
- 浏览器端：导入、选择、量测、修改不串实例、循环块拒绝提示、缩放不改量测、审图记录可指回。


## 图纸窗口裁切
打开 `/clip.html`，窗口使用图纸坐标，下载连续几何片段的参数范围、端点、包围盒及完整插入身份。
裁切保留真实仿射圆弧；显示采样只用于绘图，不决定交点或量测。
边界包含，单独相切的零长接触不作为片段；同一圆弧可有多个片段，按原参数方向排列。
窗口必须有限且有正宽高。裁切和缩放不修改共享块、插入参数或源图纸。
